# 📊 Marketing Campaign Data Analysis & Insights

## 📌 Project Overview

This project analyzes **marketing campaign data** using **Microsoft Power BI and DAX** to understand campaign performance, channel effectiveness, conversion behavior, and marketing cost efficiency.

The project transforms raw marketing campaign data into an interactive Power BI dashboard that helps identify performance trends and provides actionable business insights.

---

## 🎯 Project Objectives

* Analyze overall marketing campaign performance.
* Compare performance across different marketing channels.
* Analyze clicks, conversions, CTR, and conversion rate.
* Evaluate campaign spending and cost efficiency.
* Compare campaign performance across years.
* Identify high-performing and underperforming campaigns.
* Provide data-driven insights and recommendations.

## 🧹 Data Preprocessing

The raw dataset was prepared using **Power Query** before creating the dashboard.

Key preprocessing steps included:

* Removing duplicate records
* Handling missing/null values
* Correcting data types
* Cleaning inconsistent values
* Formatting date-related fields

* Preparing data for analysis

## 📈 Key KPIs

The dashboard focuses on the following metrics:

* **Total Spend**
* **Total Clicks**
* **Total Conversions**
* **Average CTR**
* **Average Conversion Rate**
* **Average CPC**
* **Average Cost per Conversion**
* **Average Campaign Duration**

---

## 📊 Dashboard Pages

### 1. Campaign Overview

Provides a summary of overall campaign performance using KPI cards, charts, and trend analysis.

### 2. Channel Performance

Compares marketing channels based on clicks, conversions, CTR, and conversion rate.

### 3. Campaign Efficiency

Analyzes campaign spending and efficiency using CPC, cost per conversion, and spend-versus-conversion analysis.

### 4. Insights & Recommendations

Summarizes the major findings from the analysis and provides recommendations for improving future campaigns.

---

## 🔍 Key Insights

* Different marketing channels show different levels of engagement and conversion performance.
* High click volume does not always result in high conversions.
* CPC and cost per conversion help evaluate campaign efficiency.
* High-spending campaigns should be monitored when conversions are relatively low.
* Campaign themes can influence engagement and conversion performance.

---

## 💡 Recommendations

* Allocate budget based on both conversion performance and cost efficiency.
* Review campaigns with high spending but low conversions.
* Improve targeting, landing pages, and calls-to-action for low-converting campaigns.
* Monitor **CTR, Conversion Rate, CPC, and Cost per Conversion** together.
* Analyze successful campaign themes and strategies for future campaigns.
* Regularly compare performance by channel and year.
